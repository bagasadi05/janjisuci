# JanjiSuci.id 💍

**Platform Undangan Pernikahan Digital Premium & Modern**

JanjiSuci.id adalah platform katalog dan pembuatan undangan pernikahan online berbasis web yang elegan, interaktif, responsif, dan siap disebarkan ke ribuan tamu undangan dalam hitungan menit.

---

## ✨ Fitur Unggulan

- **8 Pilihan Template Unik & Tematik**:
  1. **Exclusive Royal Navy**: Kemewahan biru navy royal dipadukan aksen emas murni, bingkai kubah (*Royal Arch*), dan lagu *Nadhif Basalamah - Penjaga Hati*.
  2. **Royal Midnight Gold**: Nuansa malam berbintang bertabur emas dengan kartu debit BNI dan lagu *Maher Zain - For The Rest of My Life*.
  3. **Botanical Sage & Gold**: Desain alami sage green, segel lilin 3D (*Wax Seal*), dan lagu *Payung Teduh - Akad*.
  4. **Royal Javanese Heritage**: Kemegahan adat Jawa klasik dengan animasi Gerbang Gunungan membelah 3D dan partikel debu emas sakral.
  5. **Modern Luxury Champagne**: Gaya editorial majalah high-fashion, tirai terbuka mewah (*Vogue Curtain Split*), dan lagu *Payung Teduh - Berdua Saja*.
  6. **Celestial Midnight Star**: Romantisme langit malam berbintang dengan cincin konstelasi berputar (*Constellation Orbit*).
  7. **Rustic Terracotta Boho**: Kehangatan warna bumi terracotta, amplop kraft airmail, dan foto polaroid estetik.
  8. **Sweet Blush & Rose Peony**: Kelembutan kelopak bunga peony merah muda dan kelopak sakura melayang.

- **Dual-Experience Desktop & Mobile**:
  - Tampilan desktop layar ganda (*Dual-Column Split*) dengan kolom kiri lengket (*sticky showcase*), *live countdown timer*, dan pemutar musik piringan hitam (*vinyl disc*).
  - Tampilan mobile dengan *Cover Gate* layar penuh dan tombol buka undangan.
- **Musik Latar Otomatis**: Integrasi audio backsound Indonesia yang berputar otomatis seketika saat tamu mengklik *"Buka Undangan"*.
- **Nama Tamu Dinamis**: Personalisasi link undangan per tamu menggunakan parameter `?to=Nama+Tamu` (contoh: `?template=exclusive-navy&to=Bagas+Pratama`).
- **Fitur Lengkap Undangan**:
  - Kaligrafi & Terjemahan Ayat Suci Al-Qur'an (QS. Ar-Rum: 21)
  - Detail Acara Akad & Resepsi dengan navigasi Google Maps dan tombol *Save to Calendar*
  - Hitung Mundur Acara (*Event Countdown Timer*)
  - Timeline Kisah Cinta (*Love Story*)
  - Galeri Dokumentasi Foto Pernikahan Asli dengan Lightbox HD
  - Siaran Langsung (*Live Streaming Instagram*)
  - Amplop Digital & Kado Fisik (BCA, Mandiri, DANA dengan tombol 1-klik salin)
  - Buku Tamu & RSVP Interaktif (Konfirmasi kehadiran dan feed untaian doa restu)
- **Storefront & Checkout Langsung ke WhatsApp**:
  - Pilihan paket harga fleksibel (Paket Hemat Rp 75k, Paket Exclusive Rp 109k, Paket Royal VIP Rp 149k)
  - Metode pembayaran e-wallet (GoPay, ShopeePay, DANA ke `0896-1977-4116`)
  - Form order dengan dua mode: *Booking Cepat (Data Menyusul di WA)* atau *Isi Data Lengkap*.

## 🛠️ Instalasi & Menjalankan Proyek

1. **Clone repositori**:
   ```bash
   git clone https://github.com/bagasadi05/janjisuci.git
   cd janjisuci
   ```

2. **Instal dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan local development server**:
   ```bash
   npm run dev
   ```
   Akses di peramban pada: `http://localhost:5173/`

4. **Build untuk production**:
   ```bash
   npm run build
   ```

---

## 📱 Parameter URL

- **Katalog Toko**: `http://localhost:5173/`
- **Preview Template**: `http://localhost:5173/?template=exclusive-navy`
- **Sapaan Tamu Personal**: `http://localhost:5173/?template=exclusive-navy&to=Nama+Tamu`
